# 原型设计定稿（v0）

2026-11-26 · 基于 [concept-draft.md](concept-draft.md) 与三份调研文档收敛出的第一版可实现设计基线。原草案保留作对照，本文档将其中待定的分支拍板，并划清 v0 原型与后续扩展的边界。

## 1. 世界观与叙事承载

- **梯度即地图**：部分区域掉入异界，两侧无边界、互相渗透。现代城市仍在惯性运转，越往边缘走秩序越稀薄——距离本身就是难度与异常度的梯度，地图可以一直向外长。
- **气质方向**：末世与日常运转挤在一起的怪谈感（参考 *Fallen London*、*血界战线*，设定与角色全原创）。
- **v0 叙事方式（极简词条风味）**：原型阶段不写连贯剧情段落，世界观先靠街区名、设施说明、异界环境修正与队员特质的一句话风味文本（Flavor Text）立住（参考 *Kittens Game*）。
- **后续叙事接口预留**：游戏状态与存档结构从一开始预留「周回计数 / 轮回状态标志位」与事件挂载点，供后续单独填入主线剧情、周回变动与世界真相。

## 2. 玩家身份与双层空间

玩家扮演一个从零起步的自治组织：最初只有几个人自发守一条街，随着规模扩大逐步长出分工、部门与规章。**组织架构的成熟度，就是整个游戏的长线成长曲线。**

空间切分为两层（参考 *Against the Storm* 的王城与定居点、*Loop Hero* 的营地与远征）：

1. **组织总部（永久层）**：大渗透中不会失守的核心据点。承载永久生效的「部门与规章」（解锁自动化能力、小队编制上限、跳过前期手工操作的里程碑）、装有蓝图与战术零件的「知识库」、少量保存极品装备的「封存格」，以及跨轮回留存的「特别队员」。
2. **街区与前线基地（单轮层）**：每轮向外攻坚夺回、通电运转的城市街区与前线设施，在大渗透到来时清空重排。

## 3. 核心时间模型与双线循环

### 攻坚与挂机分离（确定性战斗 + 概率刷宝）

- **首次攻坚（秒级确定性战斗 + 战报调优）**：进攻未夺回的街区或首通新的异界深度时，秒级跑完一场**战斗过程无随机**的自动战斗，输出完整战报日志，方便玩家像玩《圣兽之王》一样复盘哪条战术触发出了问题并微调配队，不被暴击/闪避随机数干扰判断。
- **打通后挂机（基础物资确定 + 额外掉落按轮抽取）**：节点打通后转入持续挂机循环，中途不弹随机事件三选一。配置不变时，**单轮耗时 $T$、撤退档位与基础物资数量完全固定**；同时每完成一轮，独立结算一次**额外概率掉落表（Loot Roll）**（刷出装备、稀有设施/战术蓝图、特别队员线索等，参考 *Melvor Idle* 的挂机刷宝体验）。

### 街区与异界的分工

- **夺回街区（一次性占领 + 容量维持）**：
  - 打赢一次即并入组织版图，开放对应的基地设施槽位、常规物资采集与普通队员招募池。
  - **守街机制静态化**：已夺回街区持续消耗基地的「电力 / 驻守容量」以维持秩序（体现抵御异界日常渗透）。若电力或驻守容量不足，边缘街区仅**暂时停摆**，绝不倒扣或丢失已打通进度，避免挂机惩罚。
- **探索异界（不可占领 + 循环远征刷产）**：
  - 异界无法建立永久防线；首通某深度后，可派小队在该深度挂机循环远征，稳定获取基础异常素材，并按概率刷出装备、稀有蓝图与特别队员。
  - **撤退比例联动收益与爆率**（参考 *Loop Hero*）：单次远征结束方式分三档——按预设条件计划返回拿 **100% 基础物资 + 完整额外掉率**，触发残血/险情紧急撤退拿 **60% 基础物资 + 折损额外掉率**，战斗全灭仅保底带回 **30% 基础物资且不触发稀有掉落**，激励玩家优化战术达成完美撤回。

### 无硬门槛的软互锁（底盘广度 vs 质变乘数）

两边不设剧情锁或强制通关钥匙，单推任意一边都能前进，但单刷很快会撞上指数成本慢墙（参考商业调研中的性价比轮换原则）：

- **街区提供「容量底盘」**：电力上限、设施槽位、小队编制数、常规建材与普通兵源——决定组织能同时维持多大摊子。
- **异界提供「突破乘数」**：异常改造素材（让基地常规设施突破效率瓶颈）、强力装备、特别队员、高阶战术与设施蓝图——决定单支小队与单个设施的上限。

## 4. 调查员养成与自动战斗（CoC 九维 + 稀有度 + 转职技能树 + 演武偷学）

- **CoC 九维属性 + 稀有度**：每名角色拥有完整 CoC 九维（`STR / CON / SIZ / DEX / APP / INT / POW / EDU / LUK`，理智 SAN 暂不纳入）及稀有度（`N / R / SR / SSR`）。`STR/DEX/POW` 决定各系技能伤害，`CON+SIZ` 推导生命，`DEX` 决定先攻，`INT` 限制可挂载的战术槽位上限，`LUK` 提升所在小队的稀有掉落爆率；`APP / EDU / INT / POW` 同时直接决定基地设施驻扎效率与剧情/研习接口。
- **转职、职业熟练度与独立技能树**：设有 6 种可自由转职的调查员职业，每种提供职业熟练度星级（`★0–★5`，每星永久加成全属性）与 6 节点职业技能树；SSR 特别队员额外拥有专属个人技能树与独特词条。
- **演武偷学（参考 *魔界战记*）**：在「联合演武室」安排老队员指导新队员，随时间把师父的已学技能、通用特质或战术条件继承给徒弟，跨轮回亦为特别队员保留熟练度与继承库。
- **战斗骨架**：保持「前后排两列站位 + AP（主动）/ PP（被动）+ 条件优先级表（含撤退指令）」，加上「队员（含装备与词条）× 战术 × 基地支援设施」三层标签互触发。

## 5. 街区地块建设与渐进式界面（Unfolding UI）

- **地块化据点与二阶产线**：总部与夺回街区提供带地形加成的有限地块，自由建造发电、废材站、精密改装工坊（废材→精工零件+锻造装备）、街区联络处（`APP+LUK` 提升招募品质）、档案研习室（`EDU+INT` 产出战术手札并破译战术）与联合演武室，且调查员可在「出战」与「驻扎」之间取舍。
- **循序渐进揭示（参考 *Kittens Game* / *Magic Research*）**：初期仅展现常规废材、眼前一环街区与 2 名初始守卫；随夺回街区与解锁建筑逐步开放电网、二阶产线、迷雾异界节点、AP/PP 分栏战术编辑器与组织总部大渗透。

- **触发方式（玩家随时主动收束）**：不设真实时间倒计时或强制步数上限。越往边缘推进难度越陡，当玩家觉得当前构筑推不动、且本轮积累已够解锁新部门或新零件时，随时主动点击「收束防线」退回总部迎接大渗透——零离线暴毙风险。
- **重置与保留边界**：
  - **每轮清空**：已夺回街区、前线基地设施、常规/异界囤积资源、街区招来的普通队员、未封存的常规装备。
  - **跨轮回保留**：
    1. **总部部门与规章**：永久生效（如自动补员、自动分配电力、开局自动接管最初几条街区，跳过重复前期）。
    2. **知识库零件池**：已解锁的设施蓝图与战术指令进入总池；每轮开局按总部当前容量**挑选一部分带入本局**（保留“新选项”而非无脑叠属性，促使每轮构筑不同）。
    3. **总部封存格（装备留存）**：总部提供少量封存槽位（如 1~3 格，可随部门扩建增加，参考 *Trimps* 传家宝），允许将本轮刷到的极品装备跨轮回带入下局。
    4. **异界特别队员**：留在总部跨轮回保留核心特性，但每轮等级/养成归零重练，与每轮随机刷出的普通队员形成「老兵核心 + 新血拼图」的搭配。
- **随机性分层（战斗零随机，轮回与掉落有惊喜）**：每次大渗透重洗 ① 本轮全局异界规则修正、② 街区与异界节点分布、③ 街区普通招募的随机特性池；单轮内的**战斗推演完全确定**，随机性只保留在每轮探索结算时的**战利品抽取**上。

## 6. 技术与数值基线

- **受控小数值（原生 `number`）**：不追求突破 `1e308` 的超指数数字爆炸，不引入大数库。所有生命、护甲、电力与倍率保持在直观可读的常规数值区间，降低复杂战术条件与战斗模拟的实现负担。
- **离线收益（确定性物资直算 + 按轮次批量开箱）**：配置不变时，基地净产出速率、单轮异界巡逻耗时 $T$ 与撤退档位完全确定。离线时长 $\Delta t$ 重开时，直接算出已完成轮数 $N = \lfloor \Delta t / T \rfloor$（余数保留为当前轮进度）：基础物资直接按 $N$ 倍率发放，额外掉落执行 $N$ 次独立抽取（背包满时自动按品质择优保留或分解），瞬间完成结算且与在线挂机体验严格一致。
- **工程结构**：TypeScript + 浏览器实现，参考 `wrtsc` 与 `Synergism` 将纯函数游戏引擎（`tick` / `simulateCombat`）与 UI 完全分离；存档采用压缩 JSON + `zod` schema 校验 + 编号版本迁移。

## 7. 明确后置的内容（不在 v0 范围）

- **契约系统**：原草案设想的「基地供电与小队能力来自有期限/代价的异界契约、续约与毁约博弈」在 v0 暂不引入，发电与场外支援先直接由基地设施承担；待基础双层循环验证好玩后再评估接入。
- **完整叙事与周回真相**：v0 只铺设风味文本和轮回状态钩子，具体剧情章节、多周目世界演变与异界真相在后续阶段独立设计。
