# 设计 v2 总纲（草稿）

2026-11-28，讨论稿，还没实现。这一版是从“我们想要一个怎样的游戏”重新讨论后写的，取代同一天早些时候以“挂机 4X、铺宽还是做精”为主轴的那一稿。和 [原型 v2](prototype-v2.md)（按评估结果改出来的一版）是两回事：这里是下一版要往哪走。

本文只定骨架。展开见 [经营系统](design-v2-city.md)、[战斗系统](design-v2-combat.md)、[开局和节奏](design-v2-opening.md) 和 [引擎模型](design-v2-engine-model.md)。

## 一句话

一个挂机的城市与异界策略游戏。玩家经营一个自治组织：用小队打异界格、扩大地盘，在占下的地块上摆建筑、划街区。琢磨出一套打法后挂机，撞到瓶颈再带着攒下的新零件回来琢磨。

## 核心循环

> 琢磨出一套打法 → 挂机验收 → 撞到瓶颈 → 带着这段时间攒下的新零件再琢磨。

- “发现”（这个组合居然能这样用）和“规划验收”（我布置的计划跑成了）是这个循环的两半。
- 局内和跨局是同一个循环的两个尺度：局内攒下的是研究、候选队员、建筑；跨局带走的是队员和道具。
- 情节等玩法稳定以后再考虑。

## 想要的三种体验

| 体验 | 靠什么实现 |
|---|---|
| 人口培育出的随机队员，加上固定的特殊队员 | 随机队员来自街区人口和定制招募；特殊队员来自特殊异界格 |
| 战斗机制的联动 | 标签、反应表、学说、装备；不同性质的异界源逼出不同的队伍 |
| 城市模拟经营 | 背包式布局、地形和地块属性、街区定位、职业构成、地块上的事件 |

## 节奏

- **收菜**：每天多次，每次几分钟。领东西，处理刷新点，做简单调整。不该逼玩家做深决策。
- **规划**：一到两天一次，每次十几分钟。由瓶颈或者攒够了新零件触发，游戏要明确告诉玩家这次是哪一种上线。
- 现在只给自己玩，上面就是规格。
- 这是局变长以后的节奏。头几局很短，是坐着一口气玩完的（见下一节）。

## 一局的曲线

上面的节奏说的是一局的中后段。一局开头不是这样的，详见 [开局和节奏](design-v2-opening.md)。

| 段 | 玩家在做什么 | 反馈 |
|---|---|---|
| 轰炸期 | 亲手操作，每一下都有结果；手动的事一样样变成自动 | 极密，几秒到一两分钟一次 |
| 衰减期 | 同样的操作回报越来越慢，上线间隔自然拉长 | 逐步变疏 |
| 寻求提升 | 反馈不够了，玩家主动去找办法。核心循环从这里开始 | 靠琢磨换来大的跃升 |

- 第一层自动化在头几分钟就到，之后一层层放，最后一层留给轮回之后。
- 开局爆发和第一道墙之间，靠沿一局铺开的小爆发接上：新部门、新的敌人族、新标签、核心。
- 里程碑的间隔按倍数拉长，不是等间隔。

### 一局多长

**第一局是教学关，大约半小时；第二局起是随机地图上的正式局，长度随局外解锁增长，逐步到一周。**

| 局 | 大约多长 | 是什么 | 怎么玩 |
|---|---|---|---|
| 1 | 半小时 | 教学关。固定地图，不用随机种子。全部大系统逐个解锁，每样只做最浅的一层。以打下一个小核心收尾，然后收束，教轮回 | 坐着一口气玩完 |
| 2 | 几小时到半天 | 第一个正式局。随机地图，大系统开局就有或很快就有 | 开始有回访 |
| 之后 | 逐步到一周 | 局外解锁的深度越多，一局越长 | 收菜加规划 |

- **教学关只玩一次。** 之后每局的开头是几分钟的压缩版回顾。
- 教学关里大约一分钟一样新东西，全程是轰炸期；回馈衰减和主动寻求提升从正式局开始。每个系统只有最浅的一层：一个街区、一族敌人的第一层、一个小核心、几张研究牌。深度留给之后的局。
- **局外解锁的是深度，不是系统**：敌人的深层、更多的族、特殊异界格、品质上限、部门等级、难度条件、颠覆规则的内容。
- 正式局的长度不写死，仍由分数平台决定；结束一局永远是玩家的选择。
- 表里的长度是初步的。

## 原则

1. **只给机制，不给路线。** 不设“必须先做 X 才能做 Y”的门。哪种打法划算，由代价和收益自己平衡出来。
2. **每道墙两边都能过，代价不同。** 战斗的墙可以靠重组队伍过，也可以靠城市供的装备、定制队员、支援过；城市的墙可以靠重排街区过，也可以靠战斗带回的资源和部件过。玩家不喜欢的那一侧有省心的默认做法，效率偏低但不会卡死。
3. **瓶颈要靠想能过，不能只靠等。** 墙的形态是“这套打法对这里不灵了”，不是“再攒几个小时”。挂机攒下的主要是能改变打法的零件，数字只负责撑到下一次琢磨。
4. **时间不是敌人。** 威胁不随时间上涨。放手不管，局面会收敛到一个稳定状态，损失有上限。什么时候去探索、什么时候处理刷新点都不晚。
5. **预料不到的只有好事。** 坏事要能提前看见，损失有上限、能挽回。
6. **花了投入的都折成分数。** 分数是验收的读数，衡量打法跑得多好。
7. **回馈先自然衰减，墙在后面。** 成本按倍数涨、越往里打越费药，推进自己会慢下来；玩家是在回馈变疏之后才主动找提升的，硬墙不该出现在这之前。
8. **单局内的组合爆炸是爽点，不是要防的事。** 东西之间能互相反应、数值滚起来，正是这类游戏好玩的地方。约束它的是威胁跟分数走，和跨局只能带走有限的东西。

## 设计语法

这几轮讨论出的各种玩法，底下是同几条规则。把它们写成一套语法，用来生成内容，也用来检验新想法。玩家看到的仍然是诊所、路障、震荡，界面上不出现这些词。

**四样东西**

| | 是什么 |
|---|---|
| 实体 | 队员、敌人、建筑、装备、居民 |
| 标签 | 实体身上带的东西，可以叠层 |
| 容器 | 实体待的地方，有位置和相邻关系。城市是格子组成的容器，队伍是前后排组成的容器，街区是一组格子 |
| 路径 | 一串有先后的位置 |

**五个动词，每个一条规则**

| 动词 | 规则 |
|---|---|
| 摆 | 实体放进容器的某个位置。相邻的实体，标签互相碰到 |
| 走 | 实体沿路径依次经过各个位置，和每个位置上的东西碰一次 |
| 碰 | 两种标签相遇，按反应表反应。同种标签叠到门槛，触发效果 |
| 变 | 实体可以换一种形态进入另一类容器，标签跟着走 |
| 亮和藏 | 实体有显露和收起两种状态。分数只按显露的算足，威胁读分数 |

**一条贯穿的约定**：状态一直留着，直到被某次“碰”清掉。血量、标签、负重都是这样。

**已定的设计在语法里是什么**

| 设计 | 在语法里 |
|---|---|
| 战斗的标签和反应表 | 碰 |
| 街区属性“医疗 4/4” | 同种标签在一个容器里叠到门槛，也是碰 |
| 邻格联动、地块曾经的用途 | 摆。地块本身带一层标签 |
| 队伍的前后排站位 | 摆。队伍是一个两行三列的背包 |
| 挂机路线 | 走。敌方格子上的碰就是一场战斗；自己的格子上碰到的是建筑 |
| 来潮 | 走。来潮是敌人的路线，敌人走进玩家的容器，一路碰玩家摆的建筑 |
| 血量和医疗 | 状态保留。医疗建筑是清掉“伤”的那次碰 |
| 仿制、定制招募、占领核心 | 变 |
| 库存低权重计入威胁、带伤 | 亮和藏 |

**由此得出的三点**

1. **城市的类别和战斗的标签是同一套词汇、同一张反应表。** 跨层的联动不用逐条设计。
2. **攻守对称。** 进攻是我的队伍走进敌人的格子，防守是敌人的队伍走进我的格子。预演、战报、诊断共用。
3. **五个动词是开局揭示链的骨架**，也是总部部门的出场顺序：先走，再摆，再碰，再变，最后是亮和藏。

**怎么用**：每个新想法先问它是哪个动词的实例。需要第六个动词的想法，要认真考虑值不值得。

**语法是引擎里真正的类型**，不只是设计时的说法。细节见 [引擎模型](design-v2-engine-model.md)，要点：

- 实体声明接口（可放置、可出战、可装配等），带一张属性表和留下来的状态。装备、学说、政策、队员、建筑装上去都是“摆”。
- 上表的“容器”包括没有位置的分组：街区、阵营、敌人的族。
- 容器没有专门的行为，行为都是挂在上面的效果。效果用同一种五段句式写：时机、条件、对象、结果、代价。
- 战斗是两个容器进了同一个战场。
- **颠覆规则的内容靠解锁逐步出现。** 引擎从一开始就支持能当建筑的队员、定期交换位置这类例外，但头几局的内容里没有；一次只来一个。

## 已定

| 问题 | 定了什么 |
|---|---|
| 心脏 | 发现和规划验收，由核心循环串起来。4X 是容器，不是主轴；铺宽还是做精是循环里的一种选择 |
| 战斗的定位 | 琢磨完就能挂机，到了瓶颈再带着新资源来琢磨 |
| 两侧的关系 | 战斗给城市更大的地盘和新建筑；城市给战斗候选队员、装备和支援 |
| 进攻难度 | 看地方：离异界源多远、源有多强、是什么性质。不随分数和时间变，是玩家主动去撞的墙 |
| 防守压力 | 看统计分数（参考 RimWorld 的财富），不看时间。来潮强度跟着分数走 |
| 什么计入威胁 | 建好的、练好的按高权重；库存按低权重。仓库有上限，离线积累会停住 |
| 城市 | 背包式布局。建筑只占一格，格间和街区靠联动效果；建筑换位置、街区重划都没有代价。占多格的只有限定的中后期奇观 |
| 人口 | 做街区专精和职业构成，不做需求层级、满意度阶梯那类深模拟 |
| 地块 | 有地形，也有“曾经的用途”（比如曾经是医院），影响适合放什么建筑、划成什么街区 |
| 刷新点 | 地块上随机刷事件、战斗、物资，不在挂机路线上，要手动派人。不过期，同时存在的数量有上限，玩家可以手动删除 |
| 刷新点在哪 | 自己地盘内和已探明的外圈都有。地盘内的战斗是切磋，没有损失 |
| 迷雾 | 三态：未知、有迹象、看清。地图生成时定下的东西全图都有，包括迷雾里；游戏中刷的只出现在看得见的范围 |
| 特殊异界格 | 每局随机出现哪几种，带固定特殊队员的招募。轮回多了以后，解锁科技把异界格转成想要的种类 |
| 特殊队员 | 每种只有一名。跨局带走的名额和随机队员分开算 |
| 一局多长 | 玩家决定什么时候收束，没有固定时限 |
| 结算 | 算收束时手里有的，全部折成总分 |
| 轮回 | 带走分数记录，以及限量、由玩家自己挑的队员和道具（含图纸）。难度条件开局自选，分数乘难度系数、同榜记录 |
| 高潮 | 异界源的核心。打哪个、打几个由玩家定；打下来可以占领并开发对应科技 |
| 血量和医疗 | 队员不自动回血，血量跨战斗保留。治疗消耗医疗资源，伤越重越贵（指数）。详见战斗系统 |
| 标签 | 全游戏一套词汇、一张反应表，城市和战斗共用。标签也跨战斗保留 |
| 来潮 | 是敌人的路线，和玩家的路线用同一套规则 |
| 藏锋 | 带伤、库存不兑现这类压低读数的做法是正当打法：先藏着长，再亮出来平推 |
| 开局 | 手动起步，功能随部门逐个解锁成自动。详见开局和节奏 |
| 一局多长 | 第一局是约半小时的教学关（固定地图，只玩一次，以小核心收尾）；正式局随局外解锁变长到一周左右 |
| 引擎 | 设计语法是引擎的类型，机制是挂在上面的接口。详见引擎模型 |
| 品质 | 装备、学说、政策都带实例，出产有品质差异，不限一份 |
| 评估 | 四方分工：机器人管数值，算出来的指标管节奏的形状，LLM 管看不看得懂和打法分化，设计者自己管好不好玩 |

## 骨架

### 地图

- **随机生成**。每局形状不同，等于每局拿到一个不同的背包；种子之间不必调平，重开没有惩罚。
- **地形**：种类少，两侧都起作用。影响路线和防守，也影响能放什么建筑。
- **曾经的用途**：地块上的标签（医院、学校、工厂、车站一类）。建筑也带标签，对上了有加成，和建筑之间的联动是同一套规则。
- **异界源**：几个，强弱和性质不同。性质不同，敌人就不同，需要的队伍也不同。
- **特殊异界格**：种类每局随机，带固定特殊队员的招募。
- **奖励点**：地图生成时定下，占到或探到才拿得到。
- **刷新点**：事件、战斗、物资，游戏中随机刷在看得见的范围里。

### 迷雾

| 状态 | 玩家知道什么 |
|---|---|
| 未知 | 什么都不知道 |
| 有迹象 | 那一带有东西，不知道是什么 |
| 看清 | 种类和内容 |

- 迹象给探索一个方向。开局可以提示本局存在哪一类特殊异界格、位置未知，让玩家早早围绕它规划。
- 感知范围可以由建筑、研究和队员的能力扩大。
- 迷雾里的东西是固定的，不会因为没及时探索而错过。

### 战斗侧

详见 [战斗系统](design-v2-combat.md)，这里只列要点。

- 琢磨的对象：队伍、学说、装备、路线。
- **挂机路线**：定好以后自动打，扩大地盘。
- **手动派遣**：处理刷新点，由替补队员去，不打断挂机路线。多养的人因此有用处。
- **切磋**：自己地盘内的战斗，没有损失，用来试新编的队伍。
- 一次性的战斗适合放性质特殊的敌人，可以预演，奖励是零件。
- 琢磨需要工具：结果能预演，输了看得出为什么。

### 城市侧

详见 [经营系统](design-v2-city.md)，这里只列要点。

- 琢磨的对象：建筑摆在哪、街区怎么划、每个街区的定位、职业构成。
- **联动**：建筑和相邻建筑、建筑和地块属性、建筑和所在街区。
- **自由重摆**：没有代价。只有正在告急的格子上的建筑不能挪，免得来潮打到了再临时搬。
- **人口归街区或全城**，不绑在地块上，挪建筑不动人。
- **街区由玩家划定**，不再由地图给定。
- **自动摆放加钉子**：玩家给街区定位，锁定少数几座建筑的位置，其余自动摆。它同时是不喜欢经营的玩家的默认做法、评估机器人摆城市的办法、衡量手动琢磨比自动好多少的基准。
- **奇观**：中后期由研究解锁，占多格，数量有限。

### 队员

- **随机队员**：街区人口按职业培育出候选，可以定制（见 [想法记录](ideas.md)）。是填充和意外。
- **特殊队员**：来自特殊异界格，能力固定，每种一名。是构筑的支点，可以围绕他们提前设计打法。

### 研究

- 研究点只有一种。
- 抽卡分战斗和城市两副牌，每次研究时玩家选从哪一副抽三选一。
- 玩家不在时，研究点攒到上限，待选的卡等着，不自动选也不过期。
- 学到的学说进入一个库，按队装备。

### 威胁

- 防守压力 = 统计分数的函数。分数涨，来潮变强；丢了地、折了人，分数掉，威胁也跟着掉。
- 分数是目标，所以一直压着分数不涨等于认输。但暂时压住、攒够了再亮出来是正当打法（藏锋）：带伤的队员、不兑现的库存、收在库存里的建筑都按低权重算。
- 真正的取舍是：同样涨一分，哪种东西带来的战力多、招来的威胁少。这是数值的核心表。

## 一局怎么开始

1. **选条件**：选难度条件，选从上一局带来的队员和道具。
2. **落地**：一座小城，几格地，四周是雾。提示本局有哪类特殊异界格。
3. **亲手打头几场**：开局只有一件事可做，派人去打隔壁的格子，几秒出结果。每做成一件露出下一样：第一格、第一座建筑、第一座诊所。
4. **第一层自动化**：头几分钟内成立调度部门，路线从此自己跑。之后各部门逐个成立。
5. **回馈变疏以后**：进入“琢磨、挂机、撞墙、再琢磨”的循环。

## 一局中间

- **收菜时看到的**：占了哪些格，抽到什么研究，来了什么候选队员，刷了哪些刷新点，威胁读数。
- **撞墙**：前线打不动了，或者城市撑不起下一步。这是规划的信号。
- **过墙**：重组队伍和学说；重摆城市、换街区定位；用上新零件；或者绕到另一侧解决。
- **越往后**：离异界源越近，敌人越强、性质越特殊。奇观是布局上的大事件。

## 一局怎么结束

- 分数越高，防守压力越大。到某个点，用尽办法也没法在涨分的同时守得住，分数停在一个平台上。结束是因为到头了，不是被时间追着跑。
- 平台之后时间换不来分数，所以玩得久不占便宜。
- 收束时：结算总分，按难度记录；从这一局的队员和道具里挑有限的几样带走，特殊队员的名额另算；拿到新的解锁。

## 轮回

- **局外以拓宽为主**：解锁的是深度（敌人的深层、更多的族、特殊异界格、品质上限）、新的实体种类、难度条件、开局配置。大系统在教学关里已经全部见过。数值上的加成只用来压缩开局，而且有上限。
- **解锁靠第一次做到某件事**：打下某个核心、用某种打法到达平台。累计分数只作补充。
- **带走**：限量自选的队员和道具（现有的封存机制就是这个方向）。挑选本身是一次琢磨。
- **解锁**：新的难度条件；把异界格转成指定种类的科技。要先打下那一族的核心，才能开发对应的转化科技。
- **带走和转化的分工**：带走的是具体的一个人，带着词条和养成，立刻能用但名额少；转化得到的是这一类人的招募来源，不占名额但要重新养。
- **难度**：带走强度会让下一局变容易，由自选的难度条件对冲。

## 评估要量什么

- **每样东西的两个价格**：加多少战力，招多少威胁。现在 `eval price` 只测前一个。
- **平台分数**：各人格、各难度下分数停在哪、多久到。取代现在按 168 小时算的目标。
- **收敛检验**：从各种局面开始放手不管，要收敛到稳定状态，损失不超过上限。
- **压分检验**：一直压着分数不涨的机器人，最终分数不该超过正常玩家。先压后放的藏锋打法可以赢，另设一个人格去走它。
- **节奏的形状**：开局密度、相邻里程碑的间隔比、每种手动操作被自动化前重复了多少次（见 [开局和节奏](design-v2-opening.md)）。
- **两侧都能过墙**：`builder` 和 `tactician` 人格跑同样的局，都要能过每道墙，总分差距在一个区间内。
- **布局深度**：手动（或搜索出的）布局比自动摆放好多少。只好一点说明布局没有琢磨头。
- **刷新点**：机器人要有处理刷新点的规则，否则这部分等于没被评估。
- **LLM（涌现）**：性格只写动机和好恶，不告诉有哪些路线，事后按结局特征分堆。

## 不进首批

- **多套城市形态一键切换**。方向是存意图（街区定位加钉子）而不是存坐标，这样扩张后不用重调。要等联动做出来、确认不同局面的最优布局确实差得多再做。
- **按计划切换形态**（比如威胁读数过某个值就切到守备形态）。和战斗规划类似，有意思，但初期会增加复杂性。

## 和现在差多远

| 现在 | 要变成 |
|---|---|
| 敌人强度、来潮、研究池、分数、特殊人物都挂在“环”上 | 进攻看地方（异界源），防守看分数 |
| 来潮强度按环查表 | 跟统计分数走 |
| 一格一设施，位置定了不能挪；街区由地图给定 | 自由重摆，街区由玩家划定，有自动摆放 |
| 居民住在具体的格子里 | 人口归街区或全城 |
| 地块没有地形和曾经的用途 | 两样都有，和建筑标签联动 |
| 没有刷新点、手动派遣、切磋 | 新加 |
| 迷雾只有看得见和看不见 | 三态 |
| 军械：攒够废材和晶体就过墙 | 军械面板取消，数值成长并进街区档位 |
| 装备只靠掉落 | 加仿制：拆解得图纸，工坊量产，图纸可跨局带走 |
| 资源由建筑凭空产出，互不转换 | 两级加工链，每种资源城市和战斗各一条来路 |
| 分数看信任、人口、连片、守住的来潮、最远深度等 | 手里有的全部折算，同时用来算威胁 |
| 评估、试玩按 168 小时算 | 按平台分数和到平台的时间算 |
