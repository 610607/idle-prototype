# 设计 v2 总纲（草稿）

2026-11-28，讨论稿，还没实现。先定最上层的骨架，再展开成具体方案。和 [原型 v2](prototype-v2.md)（按评估结果改出来的一版）是两回事：这里是下一版要往哪走。

## 一句话

一局由玩家决定长短的挂机 4X。地图是随机生成的城市与异界。玩家在上面探索、扩张、开发、消灭，定好计划后离开。收束时把资源、建筑、队员都折算成总分。局与局之间主要带走广度，难度由玩家自己选，所以分数能一局比一局高。

## 已定

| 问题 | 定了什么 |
|---|---|
| 类型 | 挂机 4X。探索、扩张、开发、消灭四个方向都要有事可做，也都能折成分数 |
| 玩家角色 | 定计划的人。回来是为了看两样：门槛到了（可预期），随机奖励出来了（预料不到） |
| 主轴取舍 | 铺宽还是做精。做精两边都要有：城市（建筑往上叠）和队伍（人少但精） |
| 地图 | 每轮随机生成复杂地形，地图上有奖励点和异界格。战斗强度看离异界源多远、异界源多强，不再按环算 |
| 威胁 | 随时间慢慢涨。建筑和研究能压住它涨的速度 |
| 损失 | 玩家离开期间的损失有上限，也能挽回。预料不到的只有好事；坏事都能从威胁读数里提前看出来，也能提前买保险 |
| 研究 | 一张研究网，参考 Stellaris。研究点分几类；可研的项目按权重抽卡，满足前置才进池子；领地越大研究越贵。研究点有三个来处：建筑、勘探和奖励点、战斗残骸 |
| 资源 | 都有两条来路：战斗扩张和建设积累，各有长短。战斗只要定好路线，也能挂机 |
| 一局多长 | 玩家决定什么时候收束。现在的游戏已经是这样，但评估和试玩都按 168 小时算 |
| 结算 | 资源、建筑、队员等全部折算成总分 |
| 轮回 | 主要带走广度。难度条件开局时玩家自选，分数乘上难度系数 |
| 评估 | 机器人管数值，LLM 管涌现。不告诉 LLM 有哪些路线，事后按结局特征分堆 |

## 四条原则

1. **只给机制，不给路线。** 不设“必须先做 X 才能做 Y”的门。哪种打法划算，由代价和收益自己平衡出来。
2. **关键资源至少两条来路，两条来路的代价不同。** 战斗快，但有风险，也要先把路线定好；建设慢，但稳，会滚雪球。
3. **花了时间的都折成分数。** 玩家在哪个方向上投入，收束时都能看到回报。
4. **预料不到的只有好事。** 坏事要能提前看见、能买保险，损失有上限。

## 骨架

| 系统 | 4X 里的哪一块 | 内容 | 铺宽 / 做精 |
|---|---|---|---|
| 地图 | 探索 | 随机地形、异界源、奖励点（一次性的、能反复拿的、限时的）。威胁场由各异界源叠加：按源的强度和走过去的距离衰减，随时间上涨 | — |
| 领地 | 扩张 | 每占一格得到资源点、人口和奖励点 | 铺宽。代价：防线变长，威胁涨得更快，研究变贵 |
| 城市 | 开发 | 建筑由研究解锁，可以升级，相邻的建筑互相加成；人口转成职业 | 做精之一 |
| 队伍 | 消灭 | 装备、训练、学说。三种行动：巡逻路线（能挂机）、远征（一次性去远处的异界格）、守城 | 做精之二 |
| 研究网 | 贯穿 | 研究点分几类，抽卡选研究，解锁学说、建筑、规章、军械 | 两边都要 |

两个循环在研究网和威胁上汇合：

- **战斗循环**：队伍去打异界格，拿到资源、残骸研究点和奖励，队伍变得更强。
- **建设循环**：建筑产出资源和研究点，用来造更好的建筑。
- **汇合**：研究让两个循环互相加成。威胁逼着两个循环都分一点投入给防守。

## 一局的走向

- **开局**：小城，四周是雾，近处有几条路线。头几个门槛很快就到：第一次研究、第一次建筑升级、第一次远征。
- **中盘**：铺宽还是做精的分叉出现了，威胁开始需要应对。远处的奖励点和稀有研究带来预料不到的好事。
- **后盘**：威胁涨的速度渐渐超过压制能力，分数增长放缓。玩家自己判断什么时候收束，不靠规则规定一周。
- **收束**：结算总分，换成广度解锁。

## 每次上线

- **看**：到了哪些门槛；出了哪些随机奖励；威胁读数和预计什么时候打到；下一个门槛还要多久。
- **调**：路线、研究队列、建造队列、规章、远征。
- **离开**：计划在玩家离开期间自己跑。

## 轮回

- **带走**：新的开局、研究、地图类型和难度条件的解锁（广度）。前几轮也带一点强度，让新手觉得自己在变强。
- **难度**：开局时玩家自选条件，比如异界更强、威胁涨得更快。分数乘上系数，不设上限。
- **比分**：分数记录按难度分开比。

## 评估分工

- **机器人（数值）**：每条来路配一个机器人。量这些：产出速度，两条来路之间的换算比，到各个门槛的时间，威胁和战力两条曲线，铺宽和做精各得多少分，最佳收束时机落在哪。
- **LLM（涌现）**：性格只写动机和好恶（[性格库](prompts/personas.md)现在就是这样写的）。看三件事：结局特征会不会因性格而分开，每一堆的分数是不是都过得去，门槛和随机奖励玩家有没有感觉到。

## 和现在差多远

| 现在 | 要变成 |
|---|---|
| 研究池、敌人强度、关注度、分数、特殊人物都挂在“环”上 | 全部改成看威胁场 |
| 研究只花情报（第 n 次花 10 + 18n）；20 条学说全是战斗效果 | 研究网，研究点分类 |
| 建筑只花废材和零件，没有等级 | 由研究解锁，可以升级，有相邻加成 |
| 没有远征 | 新加远征 |
| 分数看信任、人口、连片、守住的来潮、最远深度、镇压裂隙、异界核心 | 资源、建筑、队员全部折算 |
| 评估、试玩按 168 小时算 | 收束时机本身也要评估 |

## 还开着的问题

1. 威胁要不要保证任何打法最后都压不住？压不住，收束时机就会自然出现。另一种做法是允许一直压住，只靠分数增长变慢来提示该收束了。
2. 收束分数算的是当时手里有的，还是这一局的峰值或累计？算当时手里有的，拖太久会掉分，什么时候收束才有分量；算累计的，拖着不收束永远不亏。
3. 一局长短由玩家定，总分天然偏向玩得久的人。同难度下直接比总分，还是比别的口径？
4. 研究点分几类，各对应什么？Stellaris 分三类。
5. 地图多大，异界源有几个，核心放在哪？高潮放在哪，也就是 [建议汇总](suggestions.md) 里的“定4”。
