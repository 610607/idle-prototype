# 设计 v2：经营系统（草稿）

2026-11-28，讨论稿，还没实现。[设计 v2 总纲](design-v2-outline.md) 的经营部分展开。文中的数字都是初步想法，要靠评估工具定。

## 一句话

城市是一个背包：占下的格子是背包的格子，建筑是物品，随时可以重摆。建筑按类别给街区计数，街区按计数激活属性，属性决定加成和能招什么队员。

## 层次

| 层 | 是什么 | 玩家决定什么 |
|---|---|---|
| 格子 | 最小单位。有地形、曾经的用途，可能有障碍 | 放哪座建筑 |
| 街区 | 一组连在一起的自有格子，玩家圈定 | 圈哪几格、里面放什么、用什么政策 |
| 总部 | 棋盘外的面板，里面是部门 | 先升哪几个部门 |

## 格子

- **一格一座建筑。** 这是初期的规则。
- **地形**：种类少，影响能放什么建筑，也影响路线和防守。
- **曾经的用途**：比如曾经是医院。类别对上的建筑放上去有加成；它还直接给所在街区的对应类别计数加一。
- **障碍**（参考群星早期的地块制）：
  - 部分格子有潜在的第二个建筑位，被障碍占着，比如塌了一半的大楼、异界残留。
  - 哪些格子有、是什么障碍，地图生成时定下。
  - 清障要先研究对应的科技，再花资源。
  - 少数刚占下的格子也可能要先清障才能建，这种少用，免得扩张的回报打折。
- 清障是城市侧自己扩大背包的办法，不用打仗。

## 建筑

- **建筑是物品。** 造一次就一直拥有。挪动就是重新摆，没有代价；格子失守时建筑退回库存，不销毁。
- **只有正在告急的格子上的建筑不能挪。**
- **每座建筑一个类别**，一共六类：

| 类别 | 经济上 | 对战斗侧 | 出什么人 |
|---|---|---|---|
| 居住 | 人口和人口增长 | 候选队员出得更快 | 不对应职业，提高本街区候选的品质 |
| 工坊 | 废材和零件 | 装备制造，小队装备效果 | 技师类 |
| 医疗 | 信任 | 受伤队员恢复更快 | 医护类 |
| 学术 | 研究点 | 学说，迹象的感知范围 | 学者类 |
| 守备 | 无 | 民兵和守城 | 防暴类 |
| 市集 | 资源互换，仓库上限 | 派遣处理刷新点的收益 | 侦察和后勤类 |

- 守备没有经济产出，是纯开销。分数涨、威胁涨，就得划更多格子给它，这是涨分的代价落在布局上的样子。
- **涉及游戏功能解锁的建筑都放在总部**，不上棋盘。棋盘上的建筑全都参与联动。

### 升级

- 只有三级。
- 所在街区的对应属性到第几档，建筑才能升到第几级。专精的街区才养得出高级建筑。
- 第三级二选一，比如诊所变成急救站（队员恢复更快）或防疫所（信任更高）。选了可以随时改。
- 等级不影响街区计数：三级诊所仍然算一座医疗建筑。
- 等级跟着建筑走，挪位置不丢。

### 异界特殊建筑

- 放在领地内的异界格上。
- 不参与街区属性的判定，提供特别的增益。
- 是晶体的城市来路，也是异界居民（异界侧队员）的来源。

### 奇观

中后期由研究解锁，占多格，数量有限。

## 联动

三层，每层只用一种简单规则。深度来自三层叠在一起，加上街区上限和地形的约束。

| 层 | 规则 | 例子 |
|---|---|---|
| 建筑和地块 | 类别对上地块的用途就有加成 | 诊所放在旧医院上 |
| 建筑和邻格 | 相邻有某类建筑时加成或减益，不分方向 | 工坊挨着仓库有加成；工坊挨着住宅降低居住效果 |
| 建筑和街区 | 同类计数到门槛就激活属性 | 医疗 4/4 |

- 邻格联动里有少量负面关系，否则最优解就是所有东西挤在一起。
- 首批不做带方向的、带复杂条件的联动。

## 街区

- **玩家圈定**：一组连在一起的自有格子。重划没有代价。
- **数量和大小有上限**，由总部决定。没划进街区的格子照常产出，只是拿不到街区加成；地盘大于管理能力时，多出来的地是低效的。
- **街区承担四件事**：共用一个人口池；有属性，带来街区级加成；决定培育出什么职业的候选；是守城和信任的结算单位。
- **首批只区分边界街区和内圈街区。** 街区之间相邻互相影响先不做。

### 属性

- **自动算出**：街区里同类建筑的数量（加上地块用途给的计数）到门槛就激活，数量越多档位越高。
- **可以同时有多个属性。**
- **进度要看得见**：面板上列出所有有计数的类别，激活的和没激活的都显示，比如“医疗 4/4，学术 3/5，守备 1/2”。文字版也要有。
- 玩家“指定定位”只作为给自动摆放的指令存在。

### 属性和招募

| 街区怎么摆 | 得到什么 |
|---|---|
| 一个属性堆到高档 | 基础职业，品质高 |
| 两个属性各到中档 | 混合职业，品质一般 |
| 两个属性都到高档 | 混合职业且品质高，要靠带用途的地块和清障后的第二个建筑位 |

- 激活了哪些属性，决定能出什么职业；属性的档位，决定候选的品质。
- 居住属性不对应职业，提高本街区所有候选的品质。“居住加医疗”出高品质医护，这是之前自然长出来的“育苗所”打法的正式位置。

### 大小和门槛

初步想法：街区上限 8 到 10 格，档位门槛 2、4、6 座。标准是：双属性中档摆得出来但要动脑，双属性高档只有少数好位置做得到。

## 人口

- 人口归街区，不绑在格子上，挪建筑不动人。
- 居民在本街区的建筑里上岗，岗位自动填满。
- 不做需求层级、满意度阶梯那类深模拟。也不做群星地块制里一个个安排人口到格子上的那种操作。

## 信任和政策

**信任**：每个街区一个值，跟着居民走。重划街区时居民带着各自的信任进新街区，街区信任是居民的平均。

- 涨：守住来潮、医疗属性、有利的邻格关系。
- 跌：格子告急、停电、不利的邻格关系、定制招募抽人。
- 作用：人才积累速度、人口增长、志愿民兵数量。

**政策**：城市侧的“学说”，是改规则的零件，不是单纯的加成。只做街区级，全城级的规则改动交给研究和总部。

- 槽位看信任：过门槛开一个槽，再高再开一个。
- 可选的政策看街区属性；双属性街区多出一批跨类政策，比如“共居条例”。
- 每条政策都有代价。
- 换政策没有代价。信任涨得慢，槽位数量本身就是约束。

## 资源

两级，每种都有城市和战斗两条来路：

| 资源 | 城市来路 | 战斗来路 | 主要去处 |
|---|---|---|---|
| 废材 | 废材站直接产 | 战斗掉落 | 建造、清障、加工成零件 |
| 零件 | 工坊把废材加工成零件 | 拆解掉落的装备 | 高级建筑、装备制造 |
| 晶体 | 异界格上的特殊建筑 | 靠近异界源的战斗 | 装备制造、奇观、转化异界格 |
| 研究点 | 学术建筑（由情报转化） | 战斗残骸、探索发现 | 研究 |

- **加工是真的消耗**：工坊吃废材出零件。
- **仓库上限**来自市集类建筑，每种资源分别计。库存按低权重计入威胁（见总纲）。
- **电力**保留：发电机供、设施用，是布局之外的第二个约束。

## 招募

| 来源 | 怎么来 | 特点 |
|---|---|---|
| 自然候选 | 街区人口按属性攒人才，攒满出一名 | 职业看属性，品质看档位，词条随机 |
| 定制 | 抽走街区居民，换一名指定的候选 | 可控，代价是人口（见 [想法记录](ideas.md)） |
| 异界居民 | 领地内异界格上的特殊建筑 | 异界侧的职业，种类看这一局占到什么格 |
| 特殊队员 | 特殊异界格 | 固定能力，每种一名，跨局名额另算 |

- 招募池有上限，多出的排队不丢。
- 队员退役回原职业当教官，加快人才积累。
- 队伍名单有上限，由总部决定，分跑路线的主力和处理刷新点的替补。

## 装备

装备带标签和技能，不带随机百分比，是构筑的零件。两条来路：

- **掉落**（战斗）。
- **仿制**（城市）：
  1. 在工坊街区拆解一件掉落的装备，得到图纸，装备本身没了。
  2. 有了图纸，花零件和晶体造同款，数量不限。
  3. 图纸也可以来自研究。
  4. 工坊属性的档位决定能造多高级的装备、造得多快。
- **图纸可以跨局带走**，占道具的名额。

战斗负责发现，城市负责量产。只靠掉落也能凑齐，只是慢，而且看运气。

## 军械并进街区档位

原型 v2 的军械面板（点升级涨数值，攒够就过墙）取消。数值成长并进街区档位：工坊档位高，小队装备效果好；守备档位高，民兵强。数值仍然在涨，但是摆出来的，不是等出来的。

## 总部

管两件事：解锁功能，给出各种上限。

| 部门 | 解锁和上限 |
|---|---|
| 调度 | 路线数量，主力和替补的名额 |
| 人事 | 招募池上限，定制招募 |
| 规划 | 街区数量和大小，政策槽 |
| 工程 | 清障，建筑等级上限，奇观 |
| 研究 | 研究的选项数和队列 |
| 侦察 | 迹象的感知范围，刷新点数量上限 |
| 档案 | 跨局带走的名额，图纸 |

- **一局里升不满所有部门。** 先升哪几个，决定这一局的走向。
- **升级要资源，也要达成条件**（比如拥有几个街区、清过几处障碍），避免变成等资源。
- **部门升级是新功能出现的时刻**，是分量最重的一类爽点。
- **跨局**：解锁过的部门种类保留，等级每局重来。新玩家开局只有两三个部门。

## 守城

守城是一套由建筑、民兵、驻扎队员组成的构筑。守城战里建筑像队员一样带标签和技能，这一点沿用现状（路障给守军加固守，瞭望点给敌人挂标记并有自己的追击，诊所让守军回血）。

- **守备属性的档位**决定民兵的强度。
- **守城建筑**往战斗里加标签、效果，或者一个会出手的固定单位。
- **作用范围**：所在街区的全部边界格，挨着的格子额外加强。这样地盘扩了不用跟着搬，只在重划街区时才要重新考虑防守。
- **来潮预告**显示敌人带什么标签。来潮强度跟统计分数走（见总纲）。
- **失守**：丢掉那一格，建筑退回库存，居民到街区里别处避难。夺回来以后重新摆上就行。

## 自动摆放

- 玩家给街区定位，用钉子锁定少数几座建筑的位置，其余自动摆。
- 三个用途：不喜欢经营的玩家的默认做法；评估机器人摆城市的办法；衡量手动琢磨比自动好多少的基准。
- 多套形态一键切换、按计划切换都不进首批（见总纲）。

## 评估要量什么

在总纲列的那些之外，经营侧还要量：

- **布局深度**：手动或搜索出的布局比自动摆放好多少。
- **街区的分布**：一局结束时单属性、双属性、三属性街区各有多少。双属性高档应该少见但做得到。
- **每个类别的占比**：没有哪一类永远不建，也没有哪一类占掉大半。
- **部门的升级顺序**：不同人格应该升出不同的顺序。
- **仿制和掉落各供了多少装备**；清障和占领各供了多少建筑位。
- **资源流**：加工链会不会卡死，仓库上限多久顶满。

## 还开着的问题

1. 街区上限、档位门槛、每档加成的具体数字。
2. 现有的设施和职业怎么归到六个类别里，要补哪些建筑。
3. 邻格联动的具体清单，哪几对是负面的。
4. 障碍有哪几种，各对应什么科技。
5. 政策的清单，各类别和跨类别各几条。
6. 各部门每一级具体给多少、达成条件是什么。
7. 现有的格子类型（民居还是设施）、街区特色、裂隙三档怎么并进这套规则。
