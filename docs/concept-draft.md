# 挂机游戏概念草案

Nov 26, 2026 · @biobot

一款只给自己玩、放在 GitHub 上的挂机游戏。目前还在宏观阶段，下面是已经定下的方向和还开着的问题。标「建议」的是讨论中提出、还没细定的想法。

## 世界

世界上部分区域掉进了异界，但两侧之间没有边界，于是互相渗透。秩序半毁，城市区域却仍照常运转：现代文明还在惯性地活着，危险是一点点渗进日常里的。越往边缘走，秩序越稀薄，这个梯度本身就是地图。

气质参考：末世但现代文明仍在的那种感觉，整体更偏 Fallen London，也有点血界战线里异常与日常挤在一起的味道。世界观、名字和角色全部原创。

探索不设终点，地图可以一直往外长。异界本身是什么不重要，它主要用来提供游戏机制。

## 玩家

一个自治组织，从最小的架构起步：最初只有几个人自发守一条街，后来慢慢长出分工、部门和规章。它一边抵御异界的入侵，一边组织小队往异界那一侧探索。组织本身的成长，就是整个游戏的成长曲线。

## 玩法结构

两层，互相喂养。

1. 基地：组织的据点，负责产出和养成，以挂机为主，放着就会长。
2. 小队：战前配好队、写好战术，派出去后战斗自动打完，思路类似圣兽之王。日常探索和剧情推进是同一件事，区别只在派到多远、碰多危险的区域。剧情跟着地图向外拓展。

小队的行动分两类：

- 夺回街区：解锁更多基地功能和招募来源。
- 探索异界：获得资源和特别队员。

两边提供的资源不同，但彼此之间没有强限制门槛。

设计上要有涌现出的 combo。思路（建议）：规则本身小而简单，队员特性、战术、基地设施、契约各自带触发条件和标签，跨层互相触发，组合交给玩家去发现。

## 契约

世界观里的异界存在与城市各方靠契约维持关系，这一点也做成机制（建议）：基地的电力和小队的能力都来自契约，每份契约都有期限和代价，续约还是毁约是玩家一直在做的选择。没有官方授权的自治组织，要靠签契约才站得住脚。契约到期可以作为转生的节点（建议）。

## 还开着的问题

- 轮回：确定要做，理由是周期性的「大渗透」，吞掉街区、重排地图并改变这一轮的规则。街区和基地重置、组织保留什么还待细定（参考轮回设计调研）。
- 要不要加入 roguelike 元素。
- 技术与实现：先不细定。
