## 一段话

城市的一部分掉进了异界。两边之间没有墙，所以互相渗：路灯还亮着，电车还在跑，但隔壁那条街的雾里已经有东西在走。官方早就不管这一片了。你们是一条街上自发守夜的几个人，后来有了名字、分工和规矩，成了一个没人授权的自治组织。你们一格一格把街道拿回来，在上面重新开店、开诊所、住人，同时派小队往渗得更深的地方走。

## 几个要讲清的道理

每条都对应一个玩法，文字只在这几条里取说法，不另编。

| 玩法 | 世界里的说法 |
|---|---|
| 异界格和敌人 | 被渗透的街道。原来的东西还在，只是变了：看门的狗、变电所、巡逻的机器、招牌上的字 |
| “曾经的用途” | 每块地记得自己以前是什么。在原来是诊所的地方开诊所，事半功倍 |
| 占领和镇守度 | 一条街有人守、有人住，才算拿回来。没人守的地方会慢慢渗回去 |
| 居民和信任 | 街上本来就有人，一直没走。他们肯不肯跟你们干，看你们守不守得住 |
| 招募 | 队员都是这座城里的人，带着原来的职业和手艺：防暴警察、电工、钟楼的看守、黑诊所的大夫 |
| 标签和反应 | 异界的东西不讲这边的道理，但讲它自己的。摸清了两样东西碰在一起会怎样，就能拿来用 |
| 研究和学说 | 档案室里整理出来的经验：别人怎么死的，怎么活下来的 |
| 异界源和族 | 渗透是从几个“源”漫出来的，每个源一种性质（静电、雾、玻璃），它周围的东西都带这种性质 |
| 核心 | 源的中心。打下它，这个源就不再往外漫，还能拿它来用 |
| 威胁跟分数走 | **那边看得见你们。** 你们的地盘越亮、越富、越热闹，那边就越注意这里。藏起来的东西它看不见 |
| 来潮 | 那边注意到了以后，定时漫过来的一波 |
| 轮回和收束 | 渗透有涨有落。每隔一段，会来一次挡不住的“大渗透”，街道重排，什么都留不住。组织学会的办法是在它来之前主动“收束”：把人撤进总部，封好带得走的东西，等它过去，再从头来 |
| 带走一个人、一件东西 | 收束的时候，总部的密室只装得下这么多 |
| 局外解锁 | 组织的记性。人会换，地会变，但“我们以前打下过玻璃源”这件事留在规章和档案里 |
| 部门 | 一件事亲手做熟了，就有人专门管它 |
| 特殊队员 | 那边的人，或者在那边待得太久的人。他们不完全守这边的规矩 |

## 气质

- 末世，但日常还在。危险是渗进日常里的，不是把日常掀掉。
- 冷静、带一点干巴巴的幽默，像值夜班的人写的交接记录。不煽情，不喊口号。
- 异界是什么不解释。只写它做了什么。

## 命名的规矩

- **队员的职业**：这边的旧职业加一点变味。街头防暴卫、巷战突击手、钟楼观测手、地下外伤医、信号改装师、异常民俗学者。
- **敌人**：这边的东西加异界的性质。游荡灰雾犬、变电所看门兽、锈蚀巡逻机傀、黑墨蚀刻手、玻璃棘甲体、折射灯蛾。
- **核心**：两到四个字，像个地名或者物件。折光之心、雾心。
- **建筑**：就叫它本来的名字。废材站、诊所、档案室、哨所。不起花名。
- **组织**：没有名字，文字里就说“我们”“组织”。对玩家说话用“你们”。

## 教学关的情节

一条线：**守住自己这条街，打通往北的路，把北边那个源关掉。** 每章一句话的事。

| 章 | 发生了什么 | 收尾 |
|---|---|---|
| 一 | 只剩你一个人值夜。先把家门口几格清出来，废材站重新开工，诊所重新开门，第二个人来了。往北的路被变电所门口那只东西堵着 | 打下看门兽，路通了，看得见北边、东边、西边 |
| 二 | 门后面困着一个钟楼的看守，她一直在记那边的东西怎么动。东边的机器和信号你们原来打不动，按她记的办法能打了 | 端掉信号幽灵的巢 |
| 三 | 人多了，地方不够用，开始正经规划街区。街上亮起来以后，那边第一次注意到这里 | 守住第一次来潮 |
| 四 | 来潮是北边的玻璃源引过来的。往北推，找到它的中心 | 打下折光之心 |
| 收束 | 源关掉了，但雾在涨。老队员说这是大渗透的前兆，教你们怎么收束 | 挑一个人、一件东西带走 |

教学关不出现有名字的角色，只有职业。钟楼观测手是“她”，仅此而已。

## 提示文字的样子

一句话以内，说眼前这件事，用世界里的说法。几个样句（不是定稿，文字里的数字实现时由参数传）：

| 时点 | 样句 |
|---|---|
| 开局 | 隔壁那格有东西在动。去看看。 |
| 占下第一格 | 这格清干净了。有人守着，它就是我们的。 |
| 曾是废材站 | 这里以前是废材站。架子还在。 |
| 人快没血了 | 他撑不了下一场了。附近有间诊所，门还关着。 |
| 调度部门 | 这条路你已经亲手走了好几趟。该有人专门管这件事了。 |
| 路线停在门前 | 他们在变电所门口停下了：照现在这样打不过。 |
| 第一次反应 | 她标过的地方，再震一下，它就动不了了。 |
| 威胁读数出现 | 街上亮了。那边看见了。 |
| 小核心的预演 | 它每回合重新结一层壳。壳碎的那一下，它是软的。 |
| 收束 | 雾在涨。把要带的带上，其余的留给下一次。 |

## 局外解锁页的说法

解锁页是组织的“规章和档案”。每条写成一条记录：做到了什么，于是有了什么。

- 打下变电所的看门兽 → 北边的路通了；往后每次重来，都知道怎么找到第一条路（开放正式局）。
- 打下折光之心 → 见过玻璃是怎么碎的（开放玻璃族第二层和第二个族）。

## 以后再定

- 契约（概念草案里的建议）：电力和能力来自和那边签的约。现在的设计里没有对应的玩法，先不写进文字。
- 组织要不要有名字，队员要不要有固定的名字和对话。
- 正式局的情节：每个族一条短线，还是只靠图鉴和解锁页的记录。
- 那边“看得见你们”要不要有一个具体的形象。
