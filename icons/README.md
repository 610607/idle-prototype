# 图标集（icons/）

16×16 像素图标，一个图标一个文本文件：`icons/pixel/<id>.txt`。风格是 2026-11-27 定下的“精修像素”（A 版）：有限调色板、左上光源三级明暗、1px 墨线外描边。总览见 [preview.svg](preview.svg)。

## 文件

- `palette.txt`：唯一的颜色来源。
  - 一行一色：`字符 #rrggbb 名称`。
  - `@` 开头的行是“材质”：`@字母 暗 中 亮 名称`，三个字符都是上面定义过的颜色，只在草稿里用。
- `src/<id>.txt`：草稿，16 行 × 16 字。
  - 可以写材质大写字母，比如 `S` 钢、`U` 锈、`C` 晶体、`P` 纸/搪瓷、`Y` 警示黄、`E` 电、`X` 红、`G` 苔绿、`Q` 异界灰、`D` 深钢、`K` 沙袋、`H` 牛皮纸、`T` 亮钢。
  - 也可以直接写调色板小写字母（点睛色、接缝 `k`），它们原样保留。
- `pixel/<id>.txt`：成品，16 行 × 16 字，只含调色板字符和 `.`（透明）。由 `node icons/tools/build.mjs` 从草稿生成，不要手改有草稿的成品。
- `tools/`：
  - `build.mjs`：草稿 → 成品，并检查全部成品；
  - `sheet.mjs`：出核对用的联系表（1×/2×/3×，三种面板底色）；
  - `px.mjs`：两者共用的小工具。

构建按“左上光源”给材质上明暗：

1. 挨着透明或墨线 `k` 的像素，朝上或朝左的用亮色，朝下或朝右的用暗色，其余用中间色；
2. 外轮廓自动加 1px 墨线 `k`（4 邻域）。

所以草稿里只要画剪影和材质分区；需要内部分界时，在两块材质之间画一条 `k` 接缝。

## 单色符号

按钮里的控件符号跟着文字颜色变：

- 这一类是 `chevron-right`、`close`、`collapse`、`plus`、`minus`、`play`、`pause`、`fast-forward`、`check`。
- 它们用旧的三个字符：`#` 主墨（`currentColor`）、`+` 阴影（45%）、`*` 点缀（警示黄）。
- 它们没有草稿，直接手改成品。
- 同一个图标里不能混用单色字符和调色板字符，`build.mjs` 会拦。

## 风格规则

- 民防 × 锈蚀工业的末世调子：像老式 16px 物品图标，不是线稿。
- 墨线可以贴到边；亮色内容不超过 14×14。
- 1× 下要认得出：
  - 主体至少 2px 粗；
  - 不要孤立的单个亮像素；
  - 不要 1px 的斜线噪点。
- 每个图标最多两三种材质，加少量点睛色（眼睛、灯、火花、裂隙核心）。
- 颜色带语义，同类图标保持一致：
  - 异界的东西（敌人、裂隙、异界职业）用 `C`/`Q`/`v V p`；
  - 电和震荡用 `E`/`b B`；
  - 危险和血量用 `X`/`e`；
  - 民防设施以钢、搪瓷、警示黄为主；
  - 资源各有固定颜色：废材锈、零件钢、情报牛皮纸/黄、晶体异界紫。
- 同一类（技能、设施……）视觉分量一致，彼此轮廓不相似；六个 `tag-*` 最常用、显示最小，尤其要互相区分。
- 内容数据（`engine/content/*.json`）只存 icon id（如 `"icon": "tag-shock"`），不存图形。

## 新增或修改图标

1. 定 id：内容图标用类别前缀（class-/enemy-/equip-/fac-/prof-/rift-/skill-/tag-/trait-），界面图标用语义名（如 res-scrap、tile-hq、lock）。
2. 从相近的草稿复制一份到 `src/<id>.txt`，改轮廓和材质分区。
3. 构建：`node icons/tools/build.mjs <id>`。
4. 看联系表：`node icons/tools/sheet.mjs /tmp/x.png <id 或前缀->`。在深色底上看 1× 和 2×，确认清晰、不与同类撞轮廓。
5. 运行 `node icons/preview.mjs` 重新生成 `preview.svg`，再在 content JSON 里引用这个 id。
